## 1. Repository Setup (`ashwath2005/ashwath2005`)

GitHub displays the `README.md` on your main profile overview **only** when it is placed in a special repository matching your exact username.

1. Go to **[GitHub New Repository](https://github.com/new)**.
2. Set **Repository name**: `ashwath2005` *(GitHub will show a green banner: "You found a secret! ashwath2005/ashwath2005 is a ✨special ✨ repository")*.
3. Set **Visibility**: **Public** (required for profile display).
4. Leave *Add a README file* unchecked (we are pushing our custom repository).
5. Click **Create repository**.

## 4. GitHub Contribution Settings

To ensure your contribution graph accurately reflects all your engineering efforts:

1. Go to your **Profile page** (`https://github.com/ashwath2005`).
2. Above your contribution graph, click **Contribution settings** dropdown.
3. Check **"Private contributions"** (this turns private work and client commits into green squares without exposing proprietary repository details).
4. Set activity overview filter to show all activities.
